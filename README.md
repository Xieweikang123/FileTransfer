# 远程文件传输工具 (ftool)

一个基于 Win32 API 和 Winsock2 的轻量级远程文件传输工具，支持客户端和服务端模式。

## 功能特性

- ✅ 最小依赖：仅使用 Win32 API 和 Winsock2
- ✅ 可靠传输：解决粘包/分包问题
- ✅ 大文件支持：支持 64 位文件大小
- ✅ 进度显示：实时显示传输进度
- ✅ 错误处理：完善的错误处理和恢复机制
- ✅ 协议设计：标准化的传输协议

## 编译方法

### 使用 MinGW-w64 编译
```cmd
compile_mingw.bat
```

### 手动编译
```cmd
g++ -O2 -std=c++11 -static-libgcc -static-libstdc++ ftool.cpp -lws2_32 -o ftool.exe
```

**为什么文件这么大？**

**优势：**
- ✅ 无需额外依赖，可直接运行

### 编译器安装

如果您的系统没有安装 MinGW-w64，请按以下步骤安装：

1. **下载 MinGW-w64**
   - 官网：https://www.mingw-w64.org/
   - 或使用 MSYS2：https://www.msys2.org/

2. **添加到 PATH**
   - 将 MinGW-w64 的 bin 目录添加到系统 PATH 环境变量
   - 例如：`C:\mingw64\bin`

3. **验证安装**
   - 打开命令行，运行：`g++ --version`
   - 如果显示版本信息，说明安装成功

## 使用方法

### 服务端模式
```cmd
ftool.exe server <port> <output_dir>
```

**参数说明：**
- `port`: 监听端口号 (1-65535)
- `output_dir`: 接收文件的保存目录

**示例：**
```cmd
ftool.exe server 8080 C:\received_files
```

### 客户端模式
```cmd
ftool.exe client <host> <port> <file_path>
```

**参数说明：**
- `host`: 服务器 IP 地址
- `port`: 服务器端口号
- `file_path`: 要发送的文件路径

**示例：**
```cmd
ftool.exe client 127.0.0.1 8080 C:\test.txt
```

## 传输协议

工具使用自定义的二进制协议进行文件传输：

1. **文件名长度** (4 字节，大端字节序)
   - 发送 UTF-8 编码文件名的长度

2. **文件大小** (8 字节，大端字节序)
   - 发送文件的总字节数

3. **文件名** (变长，UTF-8 编码)
   - 发送实际的文件名

4. **文件内容** (分块传输，每块 64KB)
   - 分块发送文件内容，确保可靠传输

## 技术实现

### 核心功能
- **可靠传输**: 使用 `send_all()` 和 `recv_all()` 函数确保数据完整传输
- **文件操作**: 使用 `CreateFile`、`ReadFile`、`WriteFile` 进行文件 I/O
- **网络通信**: 基于 TCP 套接字，支持多客户端连接
- **字节序处理**: 自定义字节序转换函数，确保跨平台兼容性

### 错误处理
- 网络连接错误检测和恢复
- 文件操作错误处理
- 内存分配失败处理
- 参数验证和错误提示

### 性能优化
- 64KB 分块传输，平衡内存使用和传输效率
- 地址重用选项，支持快速重启服务
- 优化的缓冲区管理

## 使用场景

1. **局域网文件共享**: 在局域网内快速传输文件
2. **远程文件备份**: 将文件备份到远程服务器
3. **开发调试**: 在开发环境中传输测试文件
4. **系统管理**: 批量文件分发和管理

## 注意事项

1. **防火墙设置**: 确保目标端口在防火墙中开放
2. **文件权限**: 确保有足够的文件读写权限
3. **网络稳定性**: 大文件传输需要稳定的网络连接
4. **磁盘空间**: 确保目标目录有足够的磁盘空间

## 故障排除

### 常见问题

1. **编译错误**
   - 确保已安装 Visual Studio 或 MSVC 编译器
   - 确保在开发者命令行中编译

2. **连接失败**
   - 检查服务器是否正在运行
   - 检查端口号是否正确
   - 检查防火墙设置

3. **文件传输失败**
   - 检查文件是否存在且有读取权限
   - 检查目标目录是否有写入权限
   - 检查磁盘空间是否充足

### 调试信息
程序会输出详细的调试信息，包括：
- 连接状态
- 传输进度
- 错误代码和描述
- 文件操作结果
